# Commit and push straight to main

When Bob says "commit and push" here, commit on `main` and push it: no feature branch, no PR, unless he asks for one.

## Why

Bob, recorded in Claude auto memory before 2026-11-16: moot and its siblings
(loom, gremlin, nestlings, groundhog, lore, glean) are solo design repos with
linear history and no review workflow. A branch plus PR is ceremony he then
has to undo by hand. Branch only when a repo gains other contributors or he
asks for a PR.

## Triggers

commit and push, feature branch, pull request, gh pr create
