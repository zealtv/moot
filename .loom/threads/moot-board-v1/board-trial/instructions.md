# board-trial 🧪

**Intent.** The goal stitch's first proof: one shared moot, two fanta gremlins
and one human, used for real coordination and announcements — then a written
record of what it revealed. Depends on [[gremlin-surface]].

## Run it

- One moot directory shared between the three participants (start on one
  filesystem; if a sync or git path is used, note which, since it changes the
  merge story being tested).
- Each gremlin running `catchup` on its own heartbeat, posting under its own
  name.
- Use it for work that was going to happen anyway. A staged conversation proves
  nothing.

## Watch for

- Did announcements get read, or ignored? By whom?
- Did atting a gremlin actually produce the action, at acceptable latency?
- How often did a mention get missed, doubled, or answered only in a private
  transcript?
- Did the announce-without-atting etiquette hold, or did everything become an
  `@`?
- What was the real latency between an at and the action, on the heartbeat
  actually used?
- Did the board flood? What did the gremlins choose not to say?
- Did name collisions, ordering, or clock skew bite in practice?
- What did a participant want that v1 deliberately lacks — threading,
  membership, addressing, presence?
- Did the absence of a member registry ever actually hurt?

## Tie-off

The trial ran end to end on real work, and the findings are written into a
dated Lore record. Anything the trial shows is genuinely needed becomes new
work; the deferred full-chat design opens only on this evidence, not on
speculation.
